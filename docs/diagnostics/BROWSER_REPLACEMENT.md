# Замена браузера после TV Bro

Пользователь проверил TV Bro 2.1.6, затем сообщил, что управление неудобно, и попросил простой удобный браузер без рекламы. По этому запросу установлен **No BS TV Browser 1.1.1**, `com.aengix.tvbrowser`. TV Bro оставлен для возврата; default browser и штатный HOME не менялись. Удобство нового браузера пока не проверено вручную.

## Выбор

| Вариант | Данные официального проекта | Решение |
|---|---|---|
| [No BS TV Browser](https://github.com/ZonD80/nobstvbrowser) | Закладки, адресная строка, D-pad курсор, русский интерфейс, WebView, без заявленных analytics/upsell; APK 10,65 МБ | Выбран под запрос простого интерфейса |
| [Mrowser](https://github.com/m-salehi-v/mrowser) | APK 4,85 МБ, виртуальный курсор, отдельный Media3 player и управление потоковым видео | Подходит прежде всего для видео; не установлен |
| [Arrowz](https://github.com/NoMercyLabs/Arrowz-Browser) | APK 3,90 МБ, авто focus/pointer, вкладки и фильтры; проект обозначен как in development | Интересен, но сложнее для текущего запроса; не установлен |
| [Google Chrome для Android](https://support.google.com/chrome/answer/95346?co=GENIE.Platform%3DAndroid&hl=en) | Официальная инструкция относится к телефону/планшету и установке через Google Play, Android 10+ | Это не подтверждение удобной TV-версии для данного METZ; APK с зеркал не использован |

Характеристики интерфейса — сведения авторов, а не результат нашей UI-проверки. Универсально «лучший» браузер не установлен испытанием; выбран наиболее подходящий простой кандидат.

Источник: [официальный релиз v1.1.1](https://github.com/ZonD80/nobstvbrowser/releases/tag/v1.1.1), опубликован 7 августа 2026. Получен `app-release.apk`, **10 650 924 байта**, SHA-256:

Изучены manifest и основные Activity/Browser/Download/FileOpener исходники официального tag. Объявлены INTERNET, legacy storage до API28, REQUEST_INSTALL_PACKAGES и собственное разрешение AndroidX receiver. Возможность установки скачанного APK используется через явное открытие файла; неизвестные источники агент не включал, `-g` не использовался. Нет camera/microphone/contacts/SMS/accessibility permissions. В DEX не найдены проверенные маркеры популярных ads/analytics SDK; это ограниченная статическая проверка, не полный аудит бинарника.

Причина расхождения не установлена; воспроизводимая сборка и побайтовая связь APK с исходниками не подтверждены. Проверенный факт происхождения — файл официального релиза с совпавшим hash и корректной подписью. Это не гарантия отсутствия вредоносного кода.

## Возврат и проверка

TV Bro остаётся установленным, его APK сохранён приватно. Возврат использования — открыть TV Bro и при желании поменять избранное METZ Home. Новый браузер можно удалить адресно:

```sh
adb -s '<текущее устройство>' uninstall com.aengix.tvbrowser
```

Удаление уничтожит новые закладки/данные No BS; оно не выполнялось и не является возвратом этих данных. Установка нового браузера не меняла default HOME или старые приложения. Ручная оценка: ввод адреса, курсор/прокрутка, закладки, нужные сайты и видео. Автоматизированные UI-тесты не проводились. TCL и история его удаления описаны в [инвентаризации](PACKAGE_INVENTORY.md).
