## Зависимости

Recommendations обслуживает не только рекламу: `.NotificationsService` связан с `system/1000` как notification listener; пакет содержит панель уведомлений, AddChannel, WatchNext и providers рекомендаций, рекламы и backdrop.

OEM customizer предоставляет `tvlauncher.config`, `tvlauncher.apprecs`, `tvlauncher.widget`; его ConfigurationProvider имеет активное соединение от recommendations. Одновременное отключение обоих не подходит для первого эксперимента.

Anoki предоставляет FastSupportProvider. Отсутствие service bindings в момент снимка не доказывает отсутствие других связей. Источник каждого рекламного блока не установлен.

Recommendations имеет отдельный UID 10005, не shared UID 1000 и не persistent. Отключение не изменяет APK штатного launcher, Cast или atvTools; косвенные последствия для HOME требуют ручной проверки.

## Одна проба — после адресного согласия

Кандидат: `com.google.android.tvrecommendations`, версия `7.4.0-848496343-f`, user 0. Исходно установлен, не hidden/suspended, override `enabled=0` (default). Приватный план: `local/recovery/recommendations-change-plan.json`.

```sh
# Применение — не выполнено
adb -s '<текущее устройство>' shell pm disable-user --user 0 com.google.android.tvrecommendations

# Точный возврат исходного override — не выполнен
adb -s '<текущее устройство>' shell pm default-state --user 0 com.google.android.tvrecommendations
```

До операции повторно проверить устройство, build, HOME и состояние пакета. Не удалять APK/данные, не менять notification-listener setting, не перезагружать ТВ и не отключать другие пакеты. Возможны потеря рекомендаций, управления каналами и панели уведомлений. Полное удаление рекламы или заметное ускорение не обещаны.

После согласованной пробы проверить ADB, override пакета, процессы/службы, PSS и память. Пользователь вручную проверяет HOME, запуск приложений, ввод/atvTools и нужные уведомления. Автоматизированный UI-тест требует отдельного разрешения. Эффект сравнивать на одном потоке с тем же качеством и сценой; idle и playback не смешивать. При ухудшении или неясном результате предложить точный возврат и согласовать его перед применением.

Включение через Settings с USB-клавиатуры — возможный, **не проверенный** запасной путь. Он может установить override 1; после восстановления ADB нужен default-state для исходного 0. Откат при потере загрузки не подтверждён: см. [план восстановления](../recovery/RECOVERY_PLAN.md).
