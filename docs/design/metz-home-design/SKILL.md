# Skill: metz-home-design

## Финальное уточнение пользователя — 9 октября 2026

Прямой запрос и два новых изображения имеют приоритет над предыдущим видом. Home0.5: убрать заголовок METZ Home, центрировать вкладки, настоящие TV banner16:9 без внешней рамки, синий спокойный фон с дешёвыми статичными изгибами. Квадратную иконку не растягивать: показать настоящее имя вместо безымянного Android placeholder. Фокус — scale/alpha150мс, учитывающий системное отключение анимаций. Без постоянных эффектов и blur. Manager0.4 следует второму референсу: навигация сверху, пульт и действия рядом, понятный статус снизу; Display встроен в «Экран», самостоятельный запуск сохранён. Диагностика только на Mac/по запросу. Дизайн изменён по прямому поручению человека; ручная приёмка ещё открыта.

## Уточнения пользователя — 9 октября 2026, Home 0.4.0

Позднейшее прямое сообщение пользователя имеет приоритет над исходными компонентными примерами ниже. Палитра, читаемость, лёгкость и единый стиль сохраняются:

- Главная — только Favorites, без Recent/диагностики; YouTube/Twitch/Browser по умолчанию.
- Приложения показываются настоящими иконками, без дополнительной толстой рамки и подписей снизу; доступные названия для accessibility сохраняются.
- На странице максимум пять приложений; продолжение — свайп или стрелки на границе ряда. Поиск — отдельная лупа с диалогом.
- Навигация Главная / Приложения / Настройки переключает страницу при переходе фокуса, без дополнительного OK. Cast перенесён в Настройки.
- Выбранная вкладка/пункт — короткая нижняя линия и жирный текст; прежние capsules/focus rings не требуются. У настроек компактный вертикальный gap, без разнесённых островов.
- Manager на Mac использует ту же палитру, несколько страниц и управление TV по явным действиям; диагностика остаётся на Mac. Blur/тени/тяжёлые анимации не добавлять.

Это зафиксированное изменение требований пользователя, а не самостоятельная смена утверждённого дизайна.

## Purpose

Используй этот skill для проектирования и реализации интерфейса **METZ Home** — лёгкого, минималистичного лаунчера для Android TV / Smart TV с ограниченными ресурсами.

Главная цель:
- сделать интерфейс красивым,
- очень читабельным с телевизионной дистанции,
- быстрым,
- простым,
- без рекламы,
- без визуального мусора,
- без тяжёлых эффектов и лишней анимации.

Этот skill обязателен для:
- главного экрана,
- всех внутренних страниц,
- состояний плиток,
- навигации,
- настроек,
- страницы приложений,
- страницы Cast,
- страницы выбора HDMI / входов,
- страницы файлов,
- любых будущих экранов METZ Home.

## Core Design Principles

1. **Минимализм**
   - Только нужные элементы.
   - Никаких декоративных перегрузок.
   - Никаких лишних секций.

2. **Производительность**
   - Дизайн должен быть лёгким для слабого ТВ.
   - Не использовать тяжёлые эффекты, которые создают лишнюю нагрузку на GPU/CPU.
   - Никаких сложных blur/shader-эффектов, real-time glow и фоновых анимаций.

3. **Читаемость**
   - Всё должно быть хорошо читаемо с расстояния.
   - Крупная типографика.
   - Чёткий контраст.
   - Короткие тексты.

4. **Единый стиль**
   - Все страницы обязаны использовать одну и ту же систему:
     - одинаковые цвета,
     - одинаковые отступы,
     - одинаковые скругления,
     - одинаковую логику фокуса,
     - одинаковые паттерны навигации.

5. **TV-first**
   - Интерфейс создаётся для телевизора, а не для телефона.
   - Навигация рассчитана на D-pad / клавиатуру / стрелки / remote input.

## Visual Style

### General Mood
- Тёмный минималистичный интерфейс.
- Спокойный premium-tech стиль.
- Без “кислотности”.
- Без золотых, кричащих, вычурных решений.
- Акцент на чистый тёмно-синий + яркий синий фокус.

### Background
Использовать:
- однотонный тёмный фон,
- либо очень лёгкий тёмно-синий градиент.

Не использовать:
- фотографии,
- обои,
- текстуры,
- шум,
- декоративные паттерны,
- живые фоны.

---

## Color Palette

Используй только эту основную палитру:

- **Primary Background**: `#0B1220`
  - основной фон приложения

- **Secondary Background / Panels**: `#111A2B`
  - карточки, панели, контейнеры

- **Accent Blue**: `#2F80FF`
  - фокус, активное состояние, выделение

- **Soft Glow Blue**: `#7DB5FF`
  - очень мягкое свечение / тень / подсветка фокуса

- **Primary Text**: `#F5F7FA`
  - основные заголовки и главный текст

- **Secondary Text**: `#AEB8C7`
  - вторичный текст, подписи, доп. информация

### Color Rules
- На одном экране должен быть **только один главный акцент**.
- Синий используется только там, где действительно нужен focus / active state.
- Не делать экран “синим целиком”.
- Чем менее важен элемент, тем меньше контраста.

---

## Typography

Используй:
- `SF Pro Display`, если доступен,
- иначе `Inter`,
- иначе системный clean sans-serif.

Типографика должна быть простой, геометричной и очень читаемой.

### Text Scale

- **H1** — 48 px / SemiBold
  - крупные главные заголовки

- **H2** — 32 px / Medium
  - заголовки экранов

- **H3** — 24 px / Medium
  - заголовки секций

- **Nav** — 18 px / Medium
  - пункты навигации

- **Tile Label** — 16 px / Regular
  - подписи плиток

- **Meta / Secondary** — 14 px / Regular
  - вспомогательная информация

### Typography Rules
- Не использовать много разных размеров.
- Не использовать декоративные шрифты.
- Не делать длинные абзацы.
- На ТВ текст должен быть коротким и быстрым для считывания.
- Заголовки — максимально короткие.
- Подписи плиток — 1 строка, максимум 2 в крайних случаях.

---

## Layout Grid and Spacing

### Safe Area
- Отступ от краёв экрана: **64 px**

### Section Spacing
- Отступ между крупными секциями: **32 px**

### Tile Spacing
- Отступ между плитками: **20 px**

### Tile Radius
- Скругление плитки: **20 px**

### Navigation Capsule Radius
- Скругление для верхней навигации / pill: **22 px**

### Focus Ring
- Толщина рамки фокуса: **3 px**

### Layout Rules
- Элементы не должны прилипать к краям.
- Воздух обязателен.
- Сетка должна быть чистой, ровной, предсказуемой.
- Не делать плотный интерфейс.
- Не ставить слишком много плиток в один ряд, если они становятся мелкими.

## Components

## 1. Top Navigation

Структура:
- слева: `METZ Home`
- по центру/рядом: пункты навигации
- справа: Wi‑Fi / статус сети / время

### Navigation Items
Базовый набор:
- `Home`
- `Apps`
- `Cast`
- `Settings`

Дополнительно допускаются:
- `Files`
- `Inputs`

Но без перегрузки.

### Navigation Rules
- Активный пункт — pill с тёмной синей подложкой и ярким focus state.
- Неактивные пункты — спокойные, без сильного контраста.
- Навигация всегда должна быть одинаковой на всех страницах.

---

## 2. Section Headers

Пример:
- `Favorites`
- `All Apps`
- `Inputs`
- `Files`
- `Settings`

Правила:
- короткие,
- крупные,
- без подзаголовков, если они не нужны.

---

## 3. Tiles / Cards

Плитки — основной паттерн интерфейса.

### Default Tile
- фон: `#111A2B`
- скругление: 20 px
- без лишней графики
- простая иконка или логотип
- короткая подпись

### Focused Tile
- яркая синяя рамка (`#2F80FF`)
- очень мягкое внешнее свечение
- можно слегка осветлить фон плитки

### Pressed Tile
- тот же focus, но с лёгким затемнением / ощущением нажатия

### Tile Content
Может содержать:
- логотип приложения,
- системную иконку,
- краткую подпись.

Не перегружать плитку:
- не добавлять длинные описания,
- не добавлять тех. информацию,
- не добавлять статус CPU / RAM,
- не делать карточки новостными баннерами.

---

## 4. Icons

Иконки должны быть:
- простыми,
- понятными,
- чистыми,
- едиными по стилю,
- без мелкой детализации.

Допустимые типы:
- line icons,
- filled icons,
- simple brand marks.

Не смешивать хаотично много разных стилей.

---

## Focus and Interaction Rules

Это критически важно для TV UI.

### Focus State
Выбранный элемент должен иметь:
- яркую синюю рамку,
- мягкое свечение,
- чёткую видимость.

### Important
Свечение должно быть **очень лёгким**.

Не использовать:
- большие размытия,
- многослойные тени,
- сложные shader glow,
- динамические expensive эффекты.

### Performance-friendly Glow
Разрешено:
- 1 тонкая рамка,
- 1 лёгкая синяя тень малой непрозрачности,
- простая анимация opacity/scale.

Пример:
- border: 3 px accent blue
- shadow: low alpha, small blur radius
- scale increase: очень лёгкое, либо вообще без scale

### Motion
Анимации:
- короткие
- быстрые
- лёгкие
- `150–200 ms`

Использовать только:
- fade,
- slight scale,
- slight elevation illusion.

Не использовать:
- spring-heavy animation,
- long transitions,
- parallax,
- particle effects,
- expensive blur transitions.

## Screen Rules

## Home Screen
Главная страница должна содержать:
- верхнюю навигацию,
- секцию `Favorites`.

### Favorites Default Apps
По умолчанию на главной должны быть:
- YouTube
- Twitch
- Browser

Дополнительно можно:
- Files
- HDMI / Inputs
- Settings

### Home Screen Restrictions
На главной **НЕ ДОЛЖНО БЫТЬ**:
- блока “Recent / Недавние”
- рекомендаций
- рекламы
- баннеров
- диаграмм
- CPU / RAM / temperature info
- блока диагностики
- системного мусора

Главная должна быть максимально чистой.

---

## All Apps Screen
Должна:
- использовать ту же навигацию,
- показывать приложения сеткой,
- сохранять те же плитки и focus logic.

Нельзя:
- менять стиль,
- делать другую систему отступов,
- вводить другой вид карточек.

---

## Cast Screen
Должна:
- быть минимальной,
- показывать доступные устройства / статус трансляции,
- использовать ту же палитру и типографику.

Не превращать её в перегруженную системную панель.

---

## Settings Screen
Должна:
- оставаться визуально лёгкой,
- делиться на понятные категории,
- использовать те же spacing rules.

Settings не должны выглядеть как Android developer menu.

---

## Inputs / HDMI Screen
Должна:
- показывать источники как плитки или список,
- использовать тот же фокус,
- быть быстрой и простой.

---

## Files Screen
Должна:
- использовать минимальный файловый вид,
- не перегружаться деталями,
- оставаться в тех же правилах дизайна.

---

## Content Rules

1. Текста мало.
2. Текст только по делу.
3. Никаких длинных описаний.
4. Никакой диагностики на ТВ.
5. Никакой системной аналитики на экране.
6. Всё техническое и диагностическое — только в **METZ Manager на Mac**, не в ТВ лаунчере.

---

## Performance Rules

Интерфейс должен быть дешёвым в отрисовке.

### Avoid
- большие blur overlays
- real-time frosted glass
- сложные drop shadows
- постоянные анимации
- gradient-heavy moving backgrounds
- heavy Compose effects without reason
- постоянное обновление данных на UI
- виджеты реального времени

### Prefer
- статичные панели
- простые rounded rectangles
- один статичный градиент на фоне
- обычные text/icon composables or lightweight native views
- ограниченное количество слоёв
- focus через border + tiny glow
- минимум пересчётов layout

### Rule
Если визуальный эффект красивый, но жрёт ресурсы, **его надо упростить или выкинуть**.

---

## Writing Style for UI Text

Используй короткие понятные слова.

Примеры:
- Home
- Apps
- Cast
- Settings
- Files
- Inputs
- Favorites

На русском, если нужен русский интерфейс:
- Главная
- Приложения
- Трансляция
- Настройки
- Файлы
- Входы
- Избранное

Не писать длинные фразы вроде:
- “Рекомендованные недавно использованные приложения”
- “Информация о системной производительности устройства”

Должно быть коротко и чисто.

---

## Consistency Rule

Все остальные экраны METZ Home должны быть созданы по этим же правилам дизайна:
- те же цвета,
- те же шрифты,
- те же отступы,
- те же скругления,
- та же логика focus state,
- тот же уровень минимализма,
- тот же уровень производительности.

Нельзя делать так, чтобы Home был красивый, а остальные экраны — “как попало”.

---

## Implementation Guidance

При создании UI:
1. Сначала проектируй структуру.
2. Потом применяй дизайн-систему.
3. Потом проверяй читаемость с TV distance.
4. Потом проверяй стоимость рендера.
5. Потом упрощай всё лишнее.

Всегда спрашивай себя:
- Это действительно нужно?
- Это не перегружает экран?
- Это не жрёт ресурсы?
- Это видно и понятно с дивана?
- Это в стиле METZ Home?

Если ответ “нет” — упростить.

---

## Final Design Goal

Итоговый METZ Home должен ощущаться как:
- чистый,
- дорогой,
- спокойный,
- быстрый,
- лёгкий,
- понятный,
- современный,
- без мусора и без лагов.

Это не “красивый концепт”.
Это **реальный TV launcher**, который должен нормально работать на слабом телевизоре.
