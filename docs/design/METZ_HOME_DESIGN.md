# METZ Home — утверждённый дизайн

Актуальные требования — финальное сообщение пользователя9 октября2026 и два новых референса: Home0.5 с центрированными вкладками без заголовка, статичным синим фоном, баннерами16:9 без обводки, понятным fallback и коротким эффектом фокуса. Manager0.4 объединяет пульт/приложения/Display/диагностику. [Результат](../FINAL_REFINEMENT.md). Следующий текст относится к прежним версиям.

Источник: прямые сообщения пользователя 9 октября 2026, два визуальных ориентира и [metz-home-design](metz-home-design/SKILL.md). Последнее уточнение пользователя зафиксировано в начале skill и имеет приоритет над прежними capsules/рамками/подписями. Глобальная установка skill не выполнялась.

Приоритет: читаемость → скорость → простота → единый стиль → красота. Kotlin/Android Views сохраняются. Палитра: фон #0B1220, панели #111A2B, акцент #2F80FF, текст #F5F7FA/#AEB8C7; системный sans-serif. Без blur, теневых шейдеров и анимаций. Safe area 48dp соответствует примерно 64px при текущей TV density; текст учитывает fontScale.

Home 0.4.0: Главная / Приложения / Настройки, переход при фокусе вкладки; активная вкладка подчёркнута и жирная. Главная только Favorites, дефолты YouTube/Twitch/Browser; сохранённые списки не заменяются. Recent/CPU/RAM отсутствуют. Настоящие app icons без внешних рамок/подписей; accessibility names сохранены. Пять приложений на странице, продолжение стрелками на краях или горизонтальным свайпом. Удержание OK/Menu открывает действия избранного; отдельная лупа — поиск. Settings компактные, gap6dp, Cast внутри Settings. Files/Inputs без готовой функции не создаются.

Иконки только из установленных приложений; cache ограничен 2МиБ и освобождается при уходе. Постоянного опроса/сетевых разрешений нет. Время — TextClock. Один видимый набор плиток; скрытых активных страниц нет. Это проектные ограничения, не измерение расхода памяти процесса.

Manager 0.3.0: Пульт / Приложения / Экран / Диагностика, общая палитра и underline/bold navigation. TV-приёмник Display — форма сопряжения и SurfaceView. Build/lint/core прошли; новый вид и реальную навигацию проверяет пользователь. Screenshots/UI-автоматизация не проводились.
