## Снимки по запросу

Нужны уже установленные Python 3.9+ и ADB. Зависимости не требуются. Сначала проверить подключение и выбрать ровно нужное устройство; не сохранять его адрес в публичных конфигурациях.

```sh
adb devices -l
python3 scripts/collect_diagnostics.py --serial '<текущее устройство из adb devices>' --profile audio --label distorted-audio
```

Профили: `maintenance` — короткое обслуживание (RAM, /data, пакеты, Home version; очищенный отчёт отдельным скриптом), `cast` — штатный Cast (службы/порты/RAM/Wi-Fi/media), `baseline` — исходное состояние, `audio` — звук, `video` — воспроизведение, `remote` — телефонные задержки (ввод, Wi-Fi, helper, HOME framestats). Скрипт только читает, не подключает и не перезагружает ТВ. Проверяет авторизацию до сбора, выполняет команды последовательно; предел одной команды 20 секунд, сохраняемого вывода — 256 КиБ на поток. Код возврата shell может относиться только к последней команде: обязательно учитывать `stderr`, `timed_out` и `truncated`.

Raw-результаты могут содержать приватные данные. Они остаются в игнорируемом `local/diagnostics/`; существующие снимки не перезаписываются. Разные условия сравнивать под разными метками. Снимок аудио желательно собрать во время естественного появления хрипа до изменения состояния устройства.
